================================================================================
                TỔNG HỢP DỮ LIỆU HỆ THỐNG ĐẶT PHÒNG KHÁCH SẠN
                    (Hotel Booking Management System)
================================================================================

📌 THÔNG TIN CHUNG VỀ PROJECT

Tên Dự Án:              Hệ Thống Đặt Phòng Khách Sạn - Microservices
Mã Dự Án:              DH13C8_PTPMHDV
Phiên Bản:             1.0.0
Tên Hệ Thống:          Mois - Hotel Booking System
Loại Dự Án:            Web Application - Microservices Architecture
Nhóm Phát Triển:       DH13C8 Team

Mục Tiêu Dự Án:
- Xây dựng nền tảng đặt phòng khách sạn trực tuyến hiện đại
- Sử dụng kiến trúc Microservices để đảm bảo khả năng mở rộng
- Cung cấp giao diện người dùng thân thiện và responsive
- Hỗ trợ các tính năng thanh toán và thông báo tự động
- Quản lý đặt phòng, người dùng, khách sạn, thanh toán tập trung

================================================================================
📊 KIẾN TRÚC HỆ THỐNG
================================================================================

1. CẤU TRÚC MICROSERVICES

Số Lượng Services:      6 Backend Services + 1 Frontend + 1 Database

Backend Services:

┌─────────────────────────────────────────────────────────────────┐
│ 1. AUTH SERVICE (Port 8021)                                     │
├─────────────────────────────────────────────────────────────────┤
│ Chức Năng:  Xác thực, đăng ký, đăng nhập, cấp phát JWT token   │
│ Công Nghệ:  Spring Boot, Spring Security, JJWT 0.11.5         │
│ Database:   Users, RefreshTokens (trong khachsan)              │
│ API:        /api/auth/register, /api/auth/login                │
│ Bảo Mật:    JWT Token, Password Encryption (BCrypt)            │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 2. USER SERVICE (Port 8022)                                     │
├─────────────────────────────────────────────────────────────────┤
│ Chức Năng:  Quản lý hồ sơ người dùng, lịch sử đặt phòng        │
│ Công Nghệ:  Spring Boot, Spring Data JPA                       │
│ Database:   Users, UserProfile, BookingHistory (khachsan)      │
│ API:        /api/users/me, /api/users/profile, /api/users/... │
│ Quyền:      GUEST, STAFF, ADMIN                                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 3. HOTEL-ROOM SERVICE (Port 8023)                              │
├─────────────────────────────────────────────────────────────────┤
│ Chức Năng:  Quản lý khách sạn, phòng, tiện nghi, tính sẵn có  │
│ Công Nghệ:  Spring Boot, Spring Data JPA, Hibernate           │
│ Database:   Hotels, Rooms, Amenities, RoomAvailability (khachsan)
│ API:        /api/hotels, /api/rooms, /api/availability        │
│ Tìm Kiếm:   Theo thành phố, ngày check-in/out, loại phòng    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 4. BOOKING SERVICE (Port 8024)                                  │
├─────────────────────────────────────────────────────────────────┤
│ Chức Năng:  Tạo/sửa/hủy đặt phòng, quản lý trạng thái         │
│ Công Nghệ:  Spring Boot, State Machine Pattern                 │
│ Database:   Bookings, BookingDetails (khachsan)                │
│ API:        /api/bookings (POST/GET/PUT/DELETE)               │
│ Trạng Thái:  PENDING, CONFIRMED, CANCELLED, COMPLETED         │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 5. PAYMENT-NOTI SERVICE (Port 8025)                             │
├─────────────────────────────────────────────────────────────────┤
│ Chức Năng:  Xử lý thanh toán, hoàn tiền, gửi email thông báo  │
│ Công Nghệ:  Spring Boot, Stripe SDK, Spring Mail              │
│ Database:   Payments, Invoices, Notifications (khachsan)      │
│ Thanh Toán:  Stripe (live mode), Mock mode                    │
│ Email:      Gmail SMTP (konfigurable)                          │
│ API:        /api/payments, /api/invoices, /api/notifications  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 6. API GATEWAY (Port 8020)                                      │
├─────────────────────────────────────────────────────────────────┤
│ Chức Năng:  Routing, JWT validation, Rate limiting, Logging   │
│ Công Nghệ:  Spring Cloud Gateway, WebFlux                     │
│ Routes:     Chuyển hướng tới 5 services theo endpoint prefix   │
│ Bảo Mật:    JWT Token Validation, Role-based Access Control   │
│ Rate Limit: Hỗ trợ (configurable)                             │
│ Logging:    Request/Response logging tập trung                │
└─────────────────────────────────────────────────────────────────┘

Frontend:

┌─────────────────────────────────────────────────────────────────┐

│ API Client: Axios (kết nối với API Gateway)                   │
│ Pages:      Home, Search, Booking, Payment, Profile, History   │

================================================================================
🗄️ CẤU TRÚC DATABASE
================================================================================

Tổng Số Bảng:          14 bảng
Character Set:         utf8mb4
Collation:            utf8mb4_unicode_ci

Danh Sách Bảng:

1. users
   - id (BIGINT, Primary Key)
   - username (VARCHAR 50, Unique)
   - email (VARCHAR 100, Unique)
   - password (VARCHAR 255)
   - full_name (VARCHAR 100)
   - phone (VARCHAR 20)
   - avatar_url (VARCHAR 500)
   - address (VARCHAR 300)
   - role (ENUM: GUEST, STAFF, ADMIN)
   - is_active (TINYINT)
   - created_at, updated_at

2. refresh_tokens
   - id (BIGINT, Primary Key)
   - user_id (BIGINT, Foreign Key -> users)
   - token (VARCHAR 512)
   - expires_at (DATETIME)
   - revoked (TINYINT)
   - created_at (DATETIME)

3. hotels
   - id (BIGINT, Primary Key)
   - name (VARCHAR 200)
   - description (TEXT)
   - city (VARCHAR 100)
   - address (VARCHAR 300)
   - phone (VARCHAR 20)
   - email (VARCHAR 100)
   - website (VARCHAR 255)
   - star_rating (DECIMAL 3,1)
   - image_url (VARCHAR 500)
   - created_at, updated_at

4. amenities
   - id (BIGINT, Primary Key)
   - name (VARCHAR 100)
   - icon (VARCHAR 100)
   - description (VARCHAR 500)
   - created_at

5. hotel_amenities
   - id (BIGINT, Primary Key)
   - hotel_id (BIGINT, Foreign Key -> hotels)
   - amenity_id (BIGINT, Foreign Key -> amenities)

6. rooms
   - id (BIGINT, Primary Key)
   - hotel_id (BIGINT, Foreign Key -> hotels)
   - room_number (VARCHAR 10)
   - room_type (VARCHAR 50)
   - capacity (INT)
   - price_per_night (DECIMAL 10,2)
   - image_url (VARCHAR 500)
   - description (TEXT)
   - status (ENUM: AVAILABLE, OCCUPIED, MAINTENANCE)
   - created_at, updated_at

7. room_availability
   - id (BIGINT, Primary Key)
   - room_id (BIGINT, Foreign Key -> rooms)
   - available_date (DATE)
   - is_available (TINYINT)

8. bookings
   - id (BIGINT, Primary Key)
   - user_id (BIGINT, Foreign Key -> users)
   - hotel_id (BIGINT, Foreign Key -> hotels)
   - room_id (BIGINT, Foreign Key -> rooms)
   - check_in (DATE)
   - check_out (DATE)
   - num_guests (INT)
   - num_nights (INT)
   - status (ENUM: PENDING, CONFIRMED, CANCELLED, COMPLETED)
   - created_at, updated_at

9. booking_details
   - id (BIGINT, Primary Key)
   - booking_id (BIGINT, Foreign Key -> bookings)
   - room_id (BIGINT, Foreign Key -> rooms)
   - price_per_night (DECIMAL 10,2)
   - num_rooms (INT)
   - subtotal (DECIMAL 12,2)

10. payments
    - id (BIGINT, Primary Key)
    - booking_id (BIGINT, Foreign Key -> bookings)
    - user_id (BIGINT, Foreign Key -> users)
    - amount (DECIMAL 12,2)
    - currency (VARCHAR 3, default: VND)
    - payment_method (ENUM: CREDIT_CARD, DEBIT_CARD, BANK_TRANSFER, WALLET)
    - status (ENUM: PENDING, SUCCESS, FAILED, REFUNDED)
    - stripe_payment_id (VARCHAR 255)
    - created_at, updated_at

11. invoices
    - id (BIGINT, Primary Key)
    - booking_id (BIGINT, Foreign Key -> bookings)
    - payment_id (BIGINT, Foreign Key -> payments)
    - subtotal (DECIMAL 12,2)
    - tax_amount (DECIMAL 12,2)
    - total_amount (DECIMAL 12,2)
    - discount (DECIMAL 12,2)
    - issued_date (DATETIME)
    - due_date (DATETIME)

12. notifications
    - id (BIGINT, Primary Key)
    - user_id (BIGINT, Foreign Key -> users)
    - type (ENUM: BOOKING, PAYMENT, SYSTEM)
    - subject (VARCHAR 255)
    - message (TEXT)
    - is_read (TINYINT)
    - created_at

13. email_logs
    - id (BIGINT, Primary Key)
    - recipient (VARCHAR 100)
    - subject (VARCHAR 255)
    - body (TEXT)
    - status (ENUM: SENT, FAILED)
    - sent_at (DATETIME)

14. audit_logs
    - id (BIGINT, Primary Key)
    - user_id (BIGINT, Foreign Key -> users)
    - action (VARCHAR 255)
    - entity_type (VARCHAR 50)
    - entity_id (BIGINT)
    - changes (JSON)
    - created_at (DATETIME)

🔐 BẢOMẶT & AUTHENTICATION
================================================================================

Phương Pháp Xác Thực:   JWT (JSON Web Token)

Token Details:
- Algorithm:           HS256 (HMAC with SHA-256)
- Secret Key:          dh13c8-khachsan-jwt-secret-key-must-be-at-least-256-bits-long-for-hs256
- Access Token TTL:    900,000 ms (15 minutes)
- Refresh Token TTL:   604,800,000 ms (7 days)

Mã Hóa Mật Khẩu:       BCrypt (Spring Security)

Vai Trò & Quyền:
- GUEST:               Xem danh sách khách sạn, tìm kiếm, đặt phòng
- STAFF:               Quản lý phòng, xem đặt phòng, xử lý thanh toán
- ADMIN:               Tất cả quyền, quản lý toàn hệ thống

API Authentication:
- Header:              Authorization: Bearer {JWT_TOKEN}
- Validation:          JWT Token được validate tại API Gateway
- Protected Routes:    Tất cả endpoint /api/** (except public)
- Public Routes:       /api/auth/register, /api/auth/login, /api/hotels/**

================================================================================
📋 DANH SÁCH CÁC API ENDPOINT CHÍNH
================================================================================

PUBLIC ENDPOINTS (Không cần JWT):

Authentication:
  POST   /api/auth/register              - Đăng ký tài khoản mới
  POST   /api/auth/login                 - Đăng nhập
  POST   /api/auth/refresh-token         - Cập nhật token

Hotels:
  GET    /api/hotels                     - Danh sách tất cả khách sạn
  GET    /api/hotels?city={city}         - Tìm khách sạn theo thành phố
  GET    /api/hotels/{id}                - Chi tiết khách sạn
  GET    /api/hotels/{id}/rooms          - Danh sách phòng của khách sạn
  GET    /api/rooms/{id}/availability    - Kiểm tra phòng trống

PROTECTED ENDPOINTS (Cần JWT token):

User Profile:
  GET    /api/users/me                   - Thông tin người dùng hiện tại
  GET    /api/users/{id}                 - Thông tin người dùng khác
  PUT    /api/users/me                   - Cập nhật hồ sơ cá nhân
  PUT    /api/users/me/password          - Đổi mật khẩu

Bookings:
  GET    /api/bookings                   - Danh sách đặt phòng của người dùng
  GET    /api/bookings/{id}              - Chi tiết đặt phòng
  POST   /api/bookings                   - Tạo đặt phòng mới
  PUT    /api/bookings/{id}              - Cập nhật đặt phòng
  DELETE /api/bookings/{id}              - Hủy đặt phòng

Payments:
  GET    /api/payments                   - Danh sách thanh toán
  POST   /api/payments                   - Tạo thanh toán
  GET    /api/payments/{id}              - Chi tiết thanh toán
  POST   /api/payments/{id}/refund       - Hoàn tiền

Invoices:
  GET    /api/invoices                   - Danh sách hóa đơn
  GET    /api/invoices/{id}              - Tải hóa đơn
  POST   /api/invoices/{id}/send         - Gửi hóa đơn qua email

Notifications:
  GET    /api/notifications              - Danh sách thông báo
  PUT    /api/notifications/{id}/read    - Đánh dấu đã đọc
  DELETE /api/notifications/{id}         - Xóa thông báo

🚀 HƯỚNG DẪN CHẠY DỰ ÁN
================================================================================

OPTION 1: CHẠY VỚI DOCKER (Recommended)

Bước 1: Chuẩn bị môi trường
  $ cp .env.example .env
  (Chỉnh sửa .env nếu cần)

Bước 2: Khởi động tất cả services
  $ docker-compose up -d

Bước 3: Kiểm tra trạng thái
  $ docker-compose ps

Bước 4: Truy cập ứng dụng
  - Frontend:    http://localhost:5173
  - API Gateway: http://localhost:8020
  - MySQL:       localhost:3306

Bước 5: Dừng services
  $ docker-compose down

OPTION 2: CHẠY LOCAL (Development)

Bước 1: Khởi động MySQL
  (Cài đặt MySQL 8.x và khởi động service)

Bước 2: Tạo database
  $ mysql -u root -p
  $ source database/schema.sql
  $ source database/data.sql

Bước 3: Chạy các backend services (trong IntelliJ hoặc terminal)
  Terminal 1: $ cd auth-service && .\mvnw.cmd spring-boot:run
  Terminal 2: $ cd user-service && .\mvnw.cmd spring-boot:run
  Terminal 3: $ cd hotel-room-service && .\mvnw.cmd spring-boot:run
  Terminal 4: $ cd booking-service && .\mvnw.cmd spring-boot:run
  Terminal 5: $ cd payment-noti-service && .\mvnw.cmd spring-boot:run
  Terminal 6: $ cd api-gateway && .\mvnw.cmd spring-boot:run

Bước 4: Chạy frontend
  $ cd frontend
  $ npm install
  $ npm run dev

Bước 5: Truy cập ứng dụng
  - Frontend:    http://localhost:5173
  - API Gateway: http://localhost:8020

OPTION 3: CHẠY TOÀN BỘ TỪ SCRIPT (Windows)

  $ .\run-all.ps1

(Script sẽ tự động khởi động tất cả services trong các cửa sổ riêng)

✅ TÍNH NĂNG CHỦ ĐẠO CỦA HỆ THỐNG
================================================================================

1. Quản Lý Người Dùng
   ✓ Đăng ký, đăng nhập, đổi mật khẩu
   ✓ Hồ sơ cá nhân, upload avatar
   ✓ Quản lý địa chỉ giao hàng/thanh toán
   ✓ Lịch sử đặt phòng
   ✓ Wishlist yêu thích

2. Tìm Kiếm & Lọc
   ✓ Tìm kiếm theo thành phố, khoảng ngày
   ✓ Lọc theo loại phòng, giá, rating
   ✓ Sắp xếp: giá (tăng/giảm), rating, phổ biến
   ✓ Xem chi tiết khách sạn, phòng, tiện nghi
   ✓ Kiểm tra sẵn có ngày cụ thể

3. Đặt Phòng & Quản Lý Booking
   ✓ Tạo đặt phòng (đơn/nhiều phòng)
   ✓ Tính toán giá (số đêm, giá mỗi đêm, thuế)
   ✓ Chỉnh sửa đặt phòng (chưa thanh toán)
   ✓ Hủy đặt phòng (với hoàn tiền nếu thỏa điều kiện)
   ✓ Quản lý trạng thái: PENDING, CONFIRMED, CANCELLED, COMPLETED

4. Thanh Toán
   ✓ Thanh toán qua thẻ tín dụng/ghi nợ (Stripe)
