🚀 START IN 5 MINUTES

1. CLONE PROJECT
   git clone https://github.com/NguyennBaViet/DH13C8_PTPMHDV.git
   cd DH13C8_PTPMHDV

2. SETUP ENVIRONMENT
   cp .env.example .env
   (Edit .env if needed, defaults work for local testing)

3. START DOCKER
   docker-compose up -d

4. WAIT 30-60 SECONDS
   (Services are starting, databases initializing)

5. ACCESS SERVICES
   Frontend:    http://localhost:5173
   API Gateway: http://localhost:8020
   MySQL:       localhost:3306

🔗 SERVICE ENDPOINTS

Public (No authentication):
  GET  /api/auth/register          - Register user
  POST /api/auth/login             - Login user
  GET  /api/hotels                 - List all hotels
  GET  /api/hotels/{id}            - Hotel details
  GET  /api/hotels/{id}/rooms      - Hotel rooms

Protected (Requires JWT token):
  GET  /api/users/me               - User profile
  GET  /api/bookings               - My bookings
  POST /api/bookings               - Create booking
  GET  /api/payments               - My payments
  POST /api/payments               - Create payment
  GET  /api/notifications/me       - My notifications

🐛 TROUBLESHOOTING

Services won't start:
  1. docker-compose ps              (check status)
  2. docker-compose logs            (view errors)
  3. docker-compose down -v && docker-compose up -d
  4. Check ports available (3306, 5173, 8020-8025)

API returns 401:
  • Token not sent in Authorization header
  • Token expired (3600 seconds)
  • Wrong JWT_SECRET in .env
  • Token invalid/malformed

Database won't connect:
  • MySQL container not running: docker-compose logs mysql
  • Wrong credentials in .env
  • Database not initialized: wait 30 seconds and refresh
