TROUBLESHOOTING GUIDE
█████████████████████████████████████████████████████████████████████████████████

If Docker containers won't start:
  1. Check Docker daemon: docker ps
  2. View errors: docker-compose logs
  3. Check port conflicts: netstat -an | grep LISTEN
  4. Verify .env file exists
  5. Rebuild: docker-compose build --no-cache

If database won't connect:
  1. Check MySQL container: docker ps | grep mysql
  2. Check logs: docker-compose logs mysql
  3. Verify credentials in .env
  4. Test connection: mysql -h 127.0.0.1 -u root -p khachsan
  5. Check port 3306 available

If services fail to start:
  1. Check Java version: docker exec <container> java -version
  2. View logs: docker-compose logs <service>
  3. Check environment: docker-compose config
  4. Verify service URLs
  5. Check database dependencies

If API returns 401 Unauthorized:
  1. Check Authorization header
  2. Verify JWT token not expired
  3. Check JWT_SECRET matches across services
  4. Verify token format (Bearer <token>)
  5. Check user roles

If payment processing fails:
  1. Check Stripe keys in .env
  2. Verify payment service logs
  3. Check database payment table
  4. Verify payment request format
  5. Test with mock payment first
