📈 SERVICE COMMUNICATION FLOW

User Request → API Gateway
                 ↓
         JWT Authentication
                 ↓
Route to Appropriate Service:
  • Auth Service (8021)      → /api/auth/**
  • User Service (8022)      → /api/users/**
  • Hotel-Room (8023)        → /api/hotels/**, /api/rooms/**
  • Booking Service (8024)   → /api/bookings/**
  • Payment-Noti (8025)      → /api/payments/**, /api/notifications/**
                 ↓
         Service-to-Service Communication:
  • Booking → Hotel-Room (check/lock rooms)
  • Booking → Payment (process payment)
  • Payment → Booking (update booking status)
  • Payment → Email (send notifications)
                 ↓
         Database (MySQL - khachsan)
                 ↓
         Response → Client
